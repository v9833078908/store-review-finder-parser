8.1 Ввести абстракцию FeedbackEvent

type: review / community_message / support_ticket

общие поля: text, lang, country/locale, timestamp, author_id (если есть), source_id, product_id

специфические поля — в raw_json_ref

Тогда ваши текущие Review — это частный случай FeedbackEvent.
